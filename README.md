## About the Portfolio

Built with Next.js, TypeScript, and Three.js, this portfolio combines an interactive 3D keyboard experience with a modern, responsive interface.

### Highlights

- Interactive 3D keyboard with sound and motion effects
- Responsive layout with light and dark themes
- Smooth scrolling and animated transitions
- Dedicated sections for projects, experience, and technical skills
- Downloadable resume and integrated contact form
- Search-engine-optimized pages and social sharing metadata

## Tech Stack

**Frontend:** Next.js, React, TypeScript, Tailwind CSS

**3D & Animation:** Three.js, Framer Motion, GSAP

**Integration:** Formspree

**Deployment:** Vercel

## Getting Started

Requirements: Node.js 22.13+ and npm 11+.

```bash
git clone https://github.com/Shivasaiyadav08/Shiva_Sai-Portfolio.git
cd Shiva_Sai-Portfolio
npm ci
npm run dev
```

Create `.env.local` from `.env.example` and configure any integrations you want to use.

Open `http://localhost:3000`.
